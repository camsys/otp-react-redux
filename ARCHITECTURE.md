# otp-react-redux (MnDOT) — architecture

System-level architecture (OTP, deployer, hub, TDS, AWS, promotion):
[`mndot-otp-v2-docker/ARCHITECTURE.md`](https://github.com/camsys/mndot-otp-v2-docker/blob/main/ARCHITECTURE.md).

## What this repo is

A React + Redux single-page app (upstream otp-react-redux, CamSys fork) that calls the OTP REST API
and renders the trip planner. It's built with **craco** (Create React App + overrides in
`craco.config.js`).

```
lib/                 the app: actions/, reducers/, components/, util/
lib/config.js        JS-level customisation hook (MnDOT replaces it at build time)
example.js / app.js  entry point that mounts the app
example-config.yml   YAML config (MnDOT replaces it at build time)
example.css          site CSS (MnDOT replaces it at build time)
craco.config.js      reads YAML_CONFIG / CUSTOM_CSS / JS_CONFIG / HTML_FILE env vars;
                     JS_CONFIG is copied to tmp/ before the build
i18n/                translations
```

## How MnDOT customises it

All MnDOT-specific files live in **`mndot-otp-v2-docker/frontend/`**, not here:

| File there | Becomes | Controls |
|---|---|---|
| `config.yml` | `example-config.yml` | Title, OTP API host (`otpv2-mndot-<env>`), map base layers (MapTiler key), geocoder (ArcGIS key), modes, menu items |
| `config.js` | `lib/config.js` | Custom panels/icons (`DefaultMainPanel`, `LineItinerary`, …) and menu links (feedback form, booking management) |
| `style.css` | `example.css` | MnDOT colours and header |

Jenkins (`mndot-otp-v2-<env>`, stage "Build Frontend Image") checks out the branch for the env, then the
tag for QA and prod, copies those three files in, and runs `yarn install --force && yarn build` on Node
18.12.1. `dist/` is tarred into the OTP frontend image, and OTP serves it with
`--clientFiles /var/otp/ui/dist --clientPath /`. In production the UI and OTP are the **same container**,
so the API is same-origin. Locally they're two processes, and OTP's CORS allows it.

## Runtime calls

- `GET {api.host}/otp/routers/default/plan?...`: itineraries
- OTP geocoding/index endpoints, plus the ArcGIS geocoder (external)
- MapTiler raster tiles (external, keyed)
- Flex legs can carry a `bookingUrl` (generated by OTP), which links to the TDS booking portal
